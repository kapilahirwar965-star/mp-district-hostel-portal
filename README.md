# मध्य प्रदेश शासन — जिला छात्रावास मॉनिटरिंग एवं स्थापना शाखा प्रबंधन पोर्टल

## 1. शून्य पूर्व-भरा डेटा (Zero Pre-filled Data Policy)
- किसी भी छात्रावास, GPS लोकेशन, कर्मचारी, पद संख्या या स्थापना आदेश का काल्पनिक डेटा इसमें शामिल नहीं है।
- अनुपलब्ध फील्ड के स्थान पर **"जानकारी दर्ज नहीं की गई"** प्रदर्शित होता है।
- जब तक वास्तविक GPS निर्देशांक दर्ज और **सत्यापित (VERIFIED)** नहीं किए जाते, मैप पर कोई Marker नहीं बनता और वह छात्रावास **"लोकेशन लंबित"** सूची में दिखता है।

## 2. अधिकृत छात्रावास प्रकार (5 Official Hostel Types)
नया छात्रावास जोड़ते समय केवल निम्नलिखित 5 विकल्पों में से प्रकार चुनना अनिवार्य है:
1. `जूनियर छात्रावास`
2. `सीनियर छात्रावास`
3. `उत्कृष्ट छात्रावास`
4. `पोस्ट-मेट्रिक छात्रावास`
5. `आश्रम छात्रावास`

पुराने विकल्प (`प्री-मैट्रिक छात्रावास`, `कन्या शिक्षा परिसर छात्रावास`, `आश्रम शाला छात्रावास`) नई चयन सूची से हटा दिए गए हैं। यदि पुराने रिकॉर्ड मौजूद हैं, तो वे बिना अनुमति डिलीट या स्वतः परिवर्तित नहीं होते; पोर्टल के **सुरक्षित माइग्रेशन पैनल** या `database/migrations/002_safe_hostel_types_migration.sql` द्वारा उनकी समीक्षा कर उन्हें नए प्रकार में माइग्रेट किया जा सकता है।

## 3. चलाने और परीक्षण करने के निर्देश (Windows / Linux / Docker)
1. **Docker के साथ चलाएँ:**
   ```bash
   cp .env.example .env
   docker compose up --build -d
   ```
   ब्राउज़र में `http://localhost:4000` खोलें।
2. **PostgreSQL + Node.js (Windows / Linux) पर मैन्युअल चलाएँ:**
   ```bash
   psql -U postgres -c "CREATE DATABASE mp_hostel_portal;"
   psql -U postgres -d mp_hostel_portal -f database/schema.sql
   # यदि पुराने डेटाबेस को माइग्रेट करना हो:
   psql -U postgres -d mp_hostel_portal -f database/migrations/002_safe_hostel_types_migration.sql
   cd backend
   cp ../.env.example .env
   npm install
   npm start
   ```
3. **स्वचालित सत्यापन परीक्षण चलाएँ:**
   ```bash
   node tests/verify_zero_data_and_crud.js
   ```
